How to approach it:
- Work hypothesis-driven. State an initial answer early, write down what would have to be true for it to hold, test each of those against the evidence, and change the answer if the evidence does not support it.
- Build the storyline with the pyramid principle: one governing thought that answers the question, an executive summary up front whose points become the sections, and the supporting arguments and evidence beneath each point.
- Keep every grouping MECE (mutually exclusive, collectively exhaustive).
- Give every slide an action title: a full-sentence takeaway that the slide's content proves.
- Base the recommendation on evidence. Quantify where the data allows and show the calculations, weigh the alternatives and their trade-offs, and state the key assumptions, risks and uncertainties.
