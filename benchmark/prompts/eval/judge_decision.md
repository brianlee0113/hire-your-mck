You are checking one strategy document for decision completeness against a reference checklist. The checklist
was written from the briefing pack alone, before any document existed. Judge only what the document contains.
Length is not a merit: a point counts if the document states and supports it, wherever it appears (main body or
appendix), however briefly.

For each checklist item, decide:
- **Constraint or known cost**: `reflected` if the recommendation's headline numbers include it or the document
  states clearly how it changes them; `mentioned` if it is named but the headline ignores it; `absent` otherwise.
- **Alternative**: `tested` if the document evaluates it with evidence and says why the recommendation beats it
  (or adopts it); `mentioned` if it is named without a test; `absent` otherwise.
- **Sensitivity**: `quantified` if the document shows how the answer moves with this input, ideally the value at
  which it flips or breaks a constraint; `mentioned` if it is only named as a risk; `absent` otherwise.

Then:
- **Overclaim**: does the governing thought or executive summary claim more certainty than the document's own
  numbers support (for example, a target "reached" only when a known cost is left out)? Quote the line if so.
- **Decision-critical omissions**: anything else, not in the checklist, that the decision maker would need and
  the document lacks. Keep this list short and specific; leave it empty if nothing material is missing.
- **Unsupported assumptions**: assumptions that carry a headline financial or strategic claim without evidence
  from the pack or a stated basis. Quote each briefly.
