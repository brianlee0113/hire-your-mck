# Onsoo Botanicals: US entry board deck

- `Onsoo_US_Entry_Board_Deck.pptx`: 21 slides (17 main + 4 appendix) for the CEO and board, March 2027 meeting.
- `model/onsoo_model.py`: the option model behind every number. Run `python3 model/onsoo_model.py` to reproduce the scenarios.

**Answer:** Enter the US in 2027 with the Amazon-led route (Option A), run as a gated programme. Do not launch national specialty retail in 2027 (Option B), and defer the Japan scale-up (Option J) to the 2028 plan.

The only input is `evidence/briefing-pack.md` (synthetic data). Where the pack was silent we made a choice and listed it on appendix slide 18. The main choices:
- "On the way to $40M by 2030" is read as $40M revenue in 2030. Slide 15 shows both readings.
- Inventory is four months of landed cost on each year's units. It is built in-year and not released by 2030.
- The evidence-based ACoS is 32%, the agency median for brands scaling from $5M to $20M. The pilot's 28% is shown as the middle case.
