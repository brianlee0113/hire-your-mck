컨설팅 장표는 20가지 유형과 몇 가지 문법으로 만들어진다

공개된 맥킨지 덱 203개의 3,257페이지를 직접 보고 태깅했습니다. 최신 덱일수록 크게 반영하고(반감기 5년), 같은 게시처의 덱이 결과를 좌우하지 않도록 상한을 뒀습니다. 생성기는 이 카탈로그를 기준으로 리드 메시지에 맞는 장표 유형을 고르고, 공통 규칙으로 검사합니다. 대상은 미국 사용자(영어)이고, 예시 제목은 모두 새로 지은 것입니다.

00 · Principles

최상위 원칙

모든 장표와 QA가 따르는 원칙입니다. Brian이 직접 쓴 원칙(B)이 Claude가 추가한 원칙(A: 덱 분석 근거, G: 일반 관행)보다 우선합니다. 전체 목록은 docs/principles.md에 있습니다.

B Brian 작성

  • B-01 리드 메시지만 읽어도 한 장이 이해돼야 한다.
  • B-02 시선은 위→아래, 좌→우로 간다. 영역마다 핵심을 먼저 말하고 부연한다.
  • B-03 한 장에 한 주제. 깊이 들어가는 건 괜찮지만, 섞지 않는다.
  • B-04 Exec Summary만 읽어도 덱 전체가 이해돼야 한다.

A Claude 추가 · 덱 분석 근거

  • A-01 제목 속 숫자는 본문에 다시 보인다.
  • A-02 제목이 지목한 것만 강조한다.
  • A-03 제목은 2줄 이내.
  • A-04 개수 단어 = 시각 요소 수.
  • A-05 절이 두 개인 제목은 2패널.
  • A-06~09 단위 줄, 출처 100%, Exec Summary 번호 = 섹션 번호, 연결어.
  • A-10 같은 그림을 다시 쓰면서 강조만 바꾼다. (v0.2)
  • A-11 차트 장표는 takeaway 사이드바가 기본. (v0.2)

G Claude 추가 · 일반 관행

  • G-01 수평 논리: 제목만 이어 읽어도 이야기가 된다.
  • G-02 수직 논리: 본문의 모든 요소는 제목을 증명한다.
  • G-03 MECE
  • G-04 피라미드 구조
  • G-05 차트 하나에 메시지 하나
01 · What slides argue

메시지 유형별 장표 수

본문 2,621장을 "무엇을 비교하는가"로 나눈 가중 비중입니다. 정량 비교 다섯 가지는 Gene Zelazny의 분류를 따랐습니다.

차트만 잘 그리는 도구는 컨설팅 덱의 절반만 만듭니다. 구조형과 텍스트형 장표가 45%, 정량 비교가 55%입니다.

02 · Routing

리드 메시지 → 장표 유형

생성기는 리드 메시지에서 비교의 종류를 판별해 1순위 유형을 고릅니다.

리드 메시지가 말하는 것신호 단어1순위대안
  • R1제목에 절이 두 개("X rose, while Y fell")면 multi-chart-panel로 2분할합니다.
  • R2제목에 개수 단어("Three drivers")가 있으면 시각 요소 수를 그 숫자에 맞춥니다.
  • R3제목이 질문형이면 답은 콜아웃이나 사이드바에 둡니다.
03 · Anatomy

모든 장표에 적용되는 공통 문법

다섯 묶음 중 세 묶음 이상에서 독립적으로 확인된 규칙만 넣었습니다.

  • T1제목은 주어와 서술어가 있는 so-what 문장입니다. 토픽 라벨은 표지, 간지, 방법론, 부록에만 씁니다.
  • A-03제목은 2줄 권장, 3줄은 경고, 25단어 초과는 실패입니다.
  • T3제목 속 숫자는 장표 안에 다시 보여야 합니다(합계 막대, 강조 막대, 콜아웃 중 하나).
  • T4제목이 지목한 항목만 강조색이고, 나머지는 중립색입니다.
  • L1단위 줄(지표, 단위, 기간)은 제목 바로 아래에 둡니다.
  • L2각주는 출처 바로 위, 출처는 좌하단에 둡니다. 데이터 장표는 출처 필수입니다(D5).
  • L3출처 없는 placeholder가 들어간 장표에는 ILLUSTRATIVE 스티커를 자동으로 붙입니다.
  • L4차트 2/3 + takeaway 1/3. 2022년 이후 차트 장표의 기본 레이아웃입니다(A-11).
  • C1막대는 값 내림차순으로 정렬하고, 막대 끝에 값을 붙이고, 값 축은 없앱니다.
  • C3Total, 평균, Other는 맨 끝에 다른 스타일로 둡니다.
03b · Style over time

스타일은 2020년을 경계로 바뀌었다

구조 문법(제목 규칙, 장표 유형)은 시기가 달라도 거의 같습니다. 바뀐 건 시각 스타일입니다. 그래서 시각 규칙은 2020년 이후 표준 템플릿 덱 99개(1,530페이지)에서만 뽑았습니다. 행사·공동 브랜드·고객 템플릿 덱 21개는 제외했습니다.

  • 제목serif 91% · sans 9% · sentence 96% · Bold 93% · 마침표 없음 98%
  • 색blue+accent 62% · mono-blue 31% · multi-color 5%. 강조색 1개, 다른 색은 의미가 있을 때만
  • 차트flat 83% · none 16% · outlined 1% · 격자선 없음 98%
  • 스티커none 70% · text-only 27% · outlined-box 3%. 테두리 박스는 옛 스타일
  • 다크어두운 덱은 반도체 협회 키노트 등 행사 덱에 집중됩니다. 기본은 밝은 덱이고, 어두운 덱은 토큰 모드로 제공합니다
  • 2026신호만 있습니다(덱 1~2개): 흰 차트 + 어두운 사이드바, 하단 결론 바, 제목 마침표. 덱이 더 쌓이면 다시 봅니다
04 · Tier 1

v1에 넣을 20가지 장표 유형

빈도가 높고 여러 덱에서 쓰인 유형에, 컨설팅을 상징하는 2x2와 이슈 트리를 더했습니다. stacked-100은 v0.2 집계에서 승격했습니다. 숫자는 주 유형으로 쓰인 장수 / 등장 덱 수 · 가중 비중입니다.

05 · Deck skeleton

덱 구조 규칙

Storyline

  • S1 Exec Summary의 번호가 각 장 제목의 번호와 섹션이 됩니다. 마지막 장에서 요약을 반복합니다.
  • S2 개요 장표가 ID(1, 2a, R1)를 부여하고, 상세 장표 제목 앞에 같은 ID를 붙입니다.
  • S4 Backup은 지원하는 본 장표 바로 뒤에 BACKUP: 접두어로 붙입니다.
  • S5 병렬 챕터는 같은 템플릿과 같은 제목 구조를 반복합니다.

Tracker와 연결

  • S3 목차를 반복하면서 현재 항목만 강조해 간지로 씁니다. 실제 덱에는 손으로 만든 tracker의 오류가 있어서, 우리는 spec에서 자동으로 만듭니다.
  • T7 "However / In addition / As a result"로 다음 장을 엽니다. 연속 장표는 (1/2)로 표시합니다.

덱 뼈대 (Nav)

  • cover 37개 덱 전부
  • agenda-tracker 목차를 반복해 현재 항목만 강조
  • section-divider 섹션 이름 + so-what 한 문장
  • end-page Key takeaways → Next steps

한계

  • 컨퍼런스 발표가 가장 많고, M&A·가격·통신 덱은 거의 없습니다.
  • mckinsey.com 자체 덱과 일본 METI는 봇 차단으로 받지 못했습니다.
  • 긴 덱은 12~30페이지만 샘플링했습니다(최신 덱일수록 많이).
